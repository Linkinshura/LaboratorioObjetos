# Instrucciones Basicas de Processing
## Funciones
```pde
void setup(){
}
```
Estas sirven para englobar bloques de codigo que cumplan una seccion del codigo, como es utilizado con funciones como Crear, Eliminar, etc

## Size();
```pde
size(x,y);
```

Indica el ancho y alto de el grafico que vamos a utilizar, siendo x el ancho e y el alto(valores fijos, no variables ni expresiones)

## Line();

```pde
line(x1,y1, x2,y2);
```
Realiza una linea desde el primer punto(x1,y1) hasta el segundo punto(x2,y2)

## Rect();

```pde
rect(x,y, width, height);
```
Realiza un rectangulo en el grafico en base a sus parametros

## Print();

```pde
print(x)
```
Imprime lo que vos le ingreses adentro

## Point();

```pde
point(50,50);
```
Dibuja un punto negro en el grafico en la posicion indicada

## Circle();
```pde
circle(x1, y1, z1);
```
Realiza un circulo en el grafico
